# Warm Library Theme

The color palette is inspired by a cozy, warm library aesthetic.

* **Primary Border / Accent:** `#D4A574` (Warm Amber)
* **Primary Text:** `#F5E6D3` (Cream)
* **Secondary Text / Active State:** `#C9B896` (Muted Beige)
* **Backgrounds:** `rgba(20, 15, 10, 0.65)` (Warm transparent black)
* **Urgent / Critical:** `#C0392B` (Soft Rust Red)
