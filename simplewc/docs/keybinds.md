# Keybinds

This setup uses **12 Workspaces (Tags)**. 

| Action | Keybind |
| :--- | :--- |
| **Switch Workspace** | `Alt + 1` through `Alt + =` |
| **Toggle Workspace View** | `Alt + Ctrl + 1` through `Alt + Ctrl + =` |
| **Send Window to Workspace** | `Alt + Shift + 1` through `Alt + Shift + =` |
| **Fix/Pin Workspace** | `Alt + Ctrl + f` |
| **App Launcher** | `Super + d` (Rofi) |
| **Power Menu** | `Super + Escape` |
| **Screenshot** | `Print` |
