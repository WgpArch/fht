# Welcome to fht-compositor Dotfiles

This is my personal configuration for **fht-compositor**, a Smithay-based dynamic tiling Wayland compositor, riced with the **Crimson Rain** theme.

## What's Included

- **fht-compositor** (Custom patched for 12 workspaces)
- **Waybar** (Sheer transparent pills with crimson accents)
- **Rofi** (Application launcher and power menu)
- **swaybg** (Wallpaper management)
- **grim** (Screenshot utility with notifications)
- **xwayland-satellite** (Seamless X11 application support)

## Color Scheme

- **Accent**: `#D32F2F` (Vibrant Crimson)
- **Background**: `#1A1A1A` (Muted Dark)
- **Borders**: `#2B2B2B` (Normal) / `#D0D0D0` (Focused)
